# 前端样式规范

管理后台使用黑、白、灰阶，保持紧凑、清晰。登录页和业务页面共用 `src/app/globals.css` 中的样式变量与组件类；Tailwind 配置负责暴露对应的尺寸和圆角。

## 基础尺度

| 项目 | 规范 | 使用方式 |
| --- | --- | --- |
| 页面背景 | `#000000` | `bg-background` |
| 卡片表面 | `#070707` | `admin-card` |
| 次级表面 / 悬停 | `#101010` / `#181818` | `bg-panel` / `bg-panelHover` |
| 边框 | 1px，`#252525`；控件 `#3a3a3a` | `border-border` / `border-borderStrong` |
| 控件圆角 | 8px | `rounded-control` |
| 卡片圆角 | 12px | `rounded-card` |
| 状态、骨架圆角 | 6px | `rounded-badge` |
| 常规控件 | 40px | `h-control` |
| 紧凑控件 | 36px，成组控件必须同时调整 | `h-control-sm` |
| 登录控件 | 44px，输入、按钮、密码切换按钮对齐 | `h-control-lg` |
| 间距 | 4px 基准；常用 8 / 12 / 16 / 24 / 32px | Tailwind `2 / 3 / 4 / 6 / 8` |
| 文字 | Geist，中文回退 Noto Sans SC | `font-sans` |
| 页面标题 | 24px / 32px，600 | `text-2xl font-semibold leading-8` |
| 正文、表单、按钮 | 14px / 20px | `text-sm leading-5` |
| 次要信息 | 12px / 16px | `text-xs leading-4` |

容器内边距一般为 16 / 24px；登录卡片手机端 24px、桌面端 32px。字段标签与输入相隔 8px，字段之间 16px，主要区块之间 24px。保留表格的行列对齐，色调圆点和加载圆环继续使用完整圆形。

## 共用组件

- `admin-card`：卡片和列表外框。表格内部只使用分隔线，不给每行增加卡片圆角。
- `admin-label`：表单标签，14px、中等字重。
- `admin-input`：统一输入框、下拉框、文本域的边框、圆角、字号和焦点状态。文本域可用 `h-auto` 调整高度。
- `admin-button`：白底主操作；`admin-secondary-button`：描边次操作。两者默认同高。
- `admin-icon-button`：44px 图标操作区域，提供可访问名称。
- `admin-alert`：灰阶提示，短句表达错误和下一步操作。
- `admin-spinner` / `admin-skeleton`：复用的加载圆环与骨架。

所有可交互控件支持键盘焦点。禁用状态同时改变交互和外观，不能只降低透明度。跟随系统的减少动态效果设置停用循环动画，保留文字状态。

## 登录页

登录卡片最大宽度 400px，水平、垂直居中，窄屏保留 16px 外边距。只显示「登录」「邮箱」「密码」以及必要的状态、错误提示。密码切换使用图标，保留屏幕阅读器名称。当前为管理员入口，沿用现有登录和权限流程。

提交状态依次为：

1. 登录：可填写表单。
2. 登录中：锁定输入和提交按钮，显示圆环及按钮底部进度动画，防止重复提交。
3. 进入中：登录成功后保持加载状态，直到控制台页面接管。
4. 失败：保留填写内容、恢复表单，显示简短中文提示，允许重试。

状态切换保持按钮和表单尺寸稳定，不添加固定等待时间。

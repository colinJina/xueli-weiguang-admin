# PVDex 辅助审核第一版

本地分支：`codex/pvdex-review-v1`。本版增加投稿详情页的辅助建议，不改数据库结构、原平台元数据获取或发布 RPC。

## 使用流程

1. 打开待审核的 Bilibili / YouTube 投稿详情。建议面板独立加载，原审核表单可继续操作。
2. 核实来源链接、匹配方式、获取时间。主视频标识或备用链接精确命中多条不同记录时，显示歧义，由管理员人工审核。
3. 勾选已有标签、色调，点击“采用勾选的建议”。分类只补空白；标签、色调追加并去重。超过 4 个标签或 3 个色调时，整次采用被拒绝，并提示减少勾选。
4. 缺失标签点击“创建并选中”，核实名称后逐项确认。缺失色调默认以大写 HEX 命名，可改名称，必须选择启用的已有色族。成功后词条立即进入选项并选中。
5. 检查人工选择、备注与原平台元数据后，点击“通过审核”完成发布。

“刷新建议”重新获取来源目录，并使用最新本地词库匹配。刷新、创建词条和页面后台重载不会重置当前审核选择。候选列表中尚未采用的勾选会在刷新时重置。

COS 投稿不加载 PVDex。未命中、来源故障、解析失败和歧义均保留人工审核能力。首次目录加载或显式刷新最多等待外部请求 15 秒。

## 数据和权限

- 服务端只读取固定地址 `https://pvdex.flux-ion.cn/api/videos`，不跟随目录中的任意链接请求。
- `tags` 和 `metrics` 兼容 JSON 字符串；视频标识、HEX 与 0–1 颜色占比经过校验。色板按占比降序，同 HEX 去重。
- 目录仅缓存解析后的必要字段，使用 Next.js `unstable_cache`，有效期 6 小时。只缓存有效目录；空目录、超限或失败结果不会写入缓存。
- 名称匹配去除首尾空白，ASCII 英文不区分大小写。重复本地匹配不任选；色调仅按同 HEX 复用，不做近似颜色替换。
- `GET /api/admin/submissions/[id]/pvdex` 每次验证管理员身份，只返回当前投稿的建议，响应为 `private, no-store`。结果状态包括 `matched`、`not_found`、`ambiguous`、`unavailable` 和 `unsupported`。
- 新建与刷新动作重新检查管理员、投稿存在且待审核、投稿来源。词条写入使用现有用户权限与 RLS；新色调验证色族存在且启用。重复写入复用已有记录；数据库唯一约束冲突后重新查询。
- 原平台数据仍写入 `auto_fetched_meta`。PVDex 既不更新它，也不绕过发布时的分类、数量、投稿状态或元数据验证。

关键实现：`src/lib/pvdex/`（目录、解析和匹配）、`src/app/api/admin/submissions/[id]/pvdex/route.ts`（管理员查询）、`src/app/dashboard/pvdex-actions.ts`（刷新与创建）、`src/lib/review/dictionary-write.ts`（共享词条写入）、`src/components/dashboard/submission-review-form.tsx` 和 `pvdex-suggestion-panel.tsx`（审核交互）。

## 验证记录

2026-10-03 对真实目录只读验证：HTTP 200，1535 条记录全部解析成功；原始 JSON 2,143,597 字节，裁剪 JSON 1,053,757 字节。含双重 JSON 编码及 1024 字节封装余量的大小检查为 1,207,091 字节，低于 2,097,152 字节上限。实际主标识与备用标识匹配均成功；目录中有 25 个标识匹配多条不同来源记录，会显示歧义。

浏览器使用实际审核组件和内存服务样本验证了：人工分类、标签和备注保留；标签/色调超额拒绝；就地新建并选中；名称框按回车不提交发布；新色调必须选择启用色族；刷新后新出现的已有词条可正常进入具名表单字段；未命中、故障、歧义和 COS 降级。控制台无错误。临时验证页已移除。未登录访问实际接口返回 401 和 `private, no-store`。

运行检查均通过：`npm run test`（12 个测试文件、149 项测试）、`npm run type-check`、`npm run lint`、`npm run build`。原发布动作回归覆盖元数据保持、RPC 参数、数量限制、已审核投稿、权限与元数据拒绝。接口与 Server Action 集成测试采用权限、查询和写入替身；本次没有写入真实数据库或发布真实投稿。

## 当前范围

建议与未提交的审核选择仅保存在当前页面。刷新浏览器或离开页面后不保留草稿；不提供跨设备草稿或持久来源快照。没有定时任务、AI 识别、自动发布、合并或部署。

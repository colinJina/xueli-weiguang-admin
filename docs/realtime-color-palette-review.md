# 实时色盘与五色审核

本次后台分支为 `codex/realtime-palette`，公开前台在独立对话的 `codex/frontend-realtime-palette` 分支开发。没有自动提交、合并或部署；2026-10-03 用户明确授权后已应用 dev 数据库扩展迁移，prod 未迁移。[撤回本次功能的步骤](realtime-color-palette-rollback.md)记录了两端修改前提交、代码保存与恢复，以及可选的完整数据库回退。本次任务未修改通知功能相关文件；前台原有未提交的推送改动当前不在工作区，其保存位置待确认。

## 后台操作

单条外链、COS 和批量审核共用视频色板，最多五色。直接选色或输入六位 HEX 即可，无需颜色名称或色族。颜色可删除、替换或补充；相同 HEX 不重复选取。人工颜色的占比为 NULL，替换建议颜色后清空占比；没有改动 HEX 时保留原占比。

PVDex 建议按占比排序。“采用前 5 色”保留现有人工色板，只从前五个建议补充剩余名额，按钮和结果消息明确显示补充数量。也可勾选颜色候选逐项采用。刷新建议不覆盖审核选择。缺失标签点击一次“创建并选中”即可按显示名称创建并采用，无需二次确认；管理员仍须点击“通过审核”才发布。

移除了色族菜单、路由、动作、校验、类型与查询。具体颜色维护页保留 HEX 和可选名称，相同 HEX 在发布事务内复用；新增颜色默认以 HEX 命名。审核不加载完整颜色词库。

## 前台与接口

固定十个圆点保留原色值与顺序，通过 HEX 自动分组。自定义颜色面板支持最多三个目标、任一或全部匹配，随操作查询，无应用按钮。拖动每 150ms 触发查询，松手立即查询最终值；过期请求取消，并用序号阻止旧响应覆盖新结果。

首屏由服务端读取，后续使用 `GET /api/archive/videos`；查询期间保留已有列表，失败提示当前为上次结果并支持重试。颜色、固定圆点、分类和标签叠加。保留 `tones=red` 等链接，新增 `colors=CF3030:30`、`colorMode=any|all`；拖动替换 URL 历史，分页、刷新和浏览器返回恢复条件。

数据库接口、建模、分组边界、精细匹配算法和分阶段迁移见 [数据库契约](realtime-color-palette-database.md)。扩展迁移须先于两个应用的正式切换，色族删除脚本须在两端切换、重新预检及外部备份完成后单独运行。

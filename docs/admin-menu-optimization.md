# 后台菜单优化与即时加载反馈

验证日期：2026-10-02。本地生产模式连接 dev Supabase `yqrnnfyzmxnqgnewrhas`。

## 菜单切换

旧侧栏的 `useTransition` 只负责侧栏高亮，右侧依赖路由 `loading.tsx`。当路由响应尚未返回时，旧页面继续显示，骨架出现过晚。

`DashboardNavigationProvider` 现在共享侧栏与右侧的导航状态。普通点击菜单或站点名称后，侧栏立即高亮目标菜单，右侧立即显示 `MenuLoading`。加载期间隐藏旧内容并设置 `inert`，防止点击旧页面操作；保留旧页面挂载，避免仅为显示骨架而重新挂载。路由提交后交给页面自身的流式加载边界，数据完成后显示目标内容。没有定时器或人为最小加载时长。链接继续通过 Next.js `onNavigate` 处理普通站内导航，保留修改键打开新标签的行为。

快速连续切换使用同一导航上下文，最终显示最后点击的菜单。色调页另加以查询参数为 key 的 Suspense 边界，修复筛选或保存后导航持续 pending 的情况。

## 其他菜单

| 菜单 | 改动 |
| --- | --- |
| 控制台 | 权限与统计并行读取；统计卡片和常用操作直达相关列表 |
| 已发布视频 | 标题搜索、来源筛选、结果总数、封面预览；分页和删除结果保留筛选；越界页恢复 |
| 首页精选 | 待处理、已应用、已拒绝、全部筛选及分页；说明替换行为；同一申请的两个操作互斥禁用 |
| 分类、标签 | 名称搜索、行内编辑；分类排序；保存反馈保留筛选；删除前二次确认 |
| 色族 | 名称或 key 搜索、启用状态筛选；编辑名称、key、排序、颜色及启用状态 |
| 色调 | 名称、HEX、色族搜索和归属筛选；空色族提示；提交后刷新默认值 |
| 共用 | 表单提交期间锁定同表单控件；错误重试页面；字典引用检查和实际更新行校验 |

字典查询改为明确列选择和稳定排序。首页精选由申请、投稿、视频三次读取合并为一次关联读取；加管理员权限检查，总数据库读取由四次降至两次。视频标题搜索将 `%`、`_`、反斜杠作为普通字符处理。所有返回地址仅接受当前菜单允许的筛选参数。

- TypeScript、ESLint、6 个文件共 69 项单元测试及隔离生产构建通过；测试覆盖查询条件、分页越界、返回参数、输入长度、重复操作、引用保护和权限错误。

- 验证快速连续点击分类、标签、色调，最终色调正确显示且 pending 清除；前进、后退和缓存路由可正常使用。
- 测试辅助脚本模拟标签读取 503：骨架结束并显示可重试错误页；恢复请求后点击重新加载可以恢复列表。

- 验证视频标题空结果、来源筛选、重置及越界恢复；精选各状态、禁用已处理操作和越界恢复；四类字典搜索、筛选保留、重置和删除确认取消。
- 分类、标签、色族、色调各执行一次原值保存到 dev，PATCH 返回成功，数据内容保持原值。没有执行真实投稿审批、精选替换、视频下架或字典删除。
- 390px 窄屏下页面无横向溢出，宽表格在容器内滚动。浏览器正常流程无 error/warn。
- 未登录请求各后台菜单均重定向登录页。

本地已有服务使用根目录 `.next`；曾出现构建清单被并发写入的问题，因此最终生产构建与浏览器回归使用 `.tmp` 内隔离副本及依赖 junction。测试代理、延迟标记和构建副本均不进入提交。

当前 dev 数据不足 20 条，实测覆盖分页越界恢复；真实多页翻页由查询单元测试覆盖。字典删除引用检查与删除是两个请求，数据库已有外键负责约束，前置检查主要提供友好提示。没有同条件性能基线，不报告耗时改善百分比。
